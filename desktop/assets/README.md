# M2Fig Logo

M2Fig 品牌图稿由项目提供者提供，原作品归相应创作者。保留原始 SVG、PNG 和生成的 Windows 图标，供本项目界面与品牌维护使用。

- `mg2fig-dark.svg` / `mg2fig-light.svg`：深色与浅色原始矢量。
- `mg2fig-dark.png` / `mg2fig-light.png`：1200 × 1200 RGBA 原始导出。
- `mg2fig.ico`：由深色 PNG 生成的 16、20、24、32、48、64、128、256px Windows 图标。

在工程根运行 `python tools/buildMg2FigIcons.py` 后重建桌面软件。运行时不依赖临时远程图片地址。
