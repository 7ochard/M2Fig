# M2Fig 桌面导出

按仓库根 README 安装并初始化本机运行环境，再启动 `M2Fig.exe`。桌面使用 Electron，导出后台使用工程内固定 Python/Node 工具；EXE 的界面运行时与后台工程依赖需要一起正确配置。

## 界面

默认内容尺寸 1100×573，顶部显示 M2Fig 品牌。左侧填写 MasterGo 链接并查看处理记录，右侧选择保存目录、启动导出或打开输出目录。下方是 Figma 导入步骤及插件 manifest 位置，路径可完整复制。窄窗口和展开说明保留换行或滚动。

- 每行一个源链接，支持文件链接或带明确文件 ID 的邀请链接。
- 每个源单独导出 ZIP；输出目录由用户选择，未知同名输出不覆盖。
- 正式设计数据来自已登录 MasterGo 桌面客户端的缓存快照，因此源文件应先打开并完整加载。
- 记录真实阶段和错误；完整日志/报告保存在本地，不把页面进度百分比当作最终验收。

## 安全与运行

界面不启动 HTTP 开发服务器；使用受限 `bridge://app/` 资源白名单、隔离 preload 与固定 IPC。没有账户口令输入功能，也不要求将客户端缓存或业务设计上传到本项目仓库。

先等待导出结束再关闭窗口。移动工程或运行时后重新初始化配置，不照抄其他电脑的绝对路径。打包完成但旧 EXE 被运行进程占用时，关闭旧窗口后重新覆盖即可，不需要结束 MasterGo 或 Figma。

插件安装及设计 ZIP 导入见 `USAGE.md` 或根 README。界面中的示例名称与截图不能作为业务迁移结果。
