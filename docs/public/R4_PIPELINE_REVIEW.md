# M2Fig r4 管线说明

r4 桌面版本为 `0.4.0`，接收插件标识为 `2026.11.06-r4.0`。沿用 v2 设计 ZIP 和 session/chunk 消息协议，不新增云服务或公共 API。

## 导出路线

桌面界面通过固定 IPC/JSON Lines 后台调用本地工具：按用户指定的 MasterGo 源 ID 读取已存在的客户端快照，核对来源身份及文档哈希，转换并独立校验设计 ZIP。快照不等同于云端最新状态；身份不明确或压缩流截断时应报错，不猜测设计数据。

图片只使用原生记录给出的精确来源，按内容和资源身份去重。图片探测使用受限并发与结果复用，单图问题应明确诊断。普通桌面导出不要求 HTTP 服务；备用 MasterGo 发送插件可使用独立的本地中继。

## Figma 还原

按选页生成必要的递归组件依赖，保留组件集与实例关系，再按页准备和分块传输。布局后处理使用适用节点队列，重复使用源文件内组件与资源身份。包含子层的文本记录由透明容器保留文本及其子层，仍保持可编辑。

发生错误时停止继续传输，保留本次有效页面与节点，输出已完成、部分保留和未开始清单；不因为最终收尾失败而删除整场成果。源记录数和 API 创建次数分别统计。

## 界面与发布边界

桌面与接收插件采用深色界面；实验室保留 ZIP 开关、字体工具、恢复默认、联系及许可。控件是否可用继续由实际状态决定。界面更新不改变数据包版本，不要求重压已经有效的设计 ZIP。

离线测试、类型检查和构建不是实际导入验收。发布记录必须单列真实 Figma 导入、GUI/DPI 和字体视觉检查是否执行，不使用历史截图冒充当前验证。
